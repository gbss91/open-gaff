A community-driven rent transparency platform for Ireland. Users can search properties, view crowd-sourced rent history, and anonymously submit what they pay — creating a public record that helps renters make informed decisions and holds the market accountable.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
